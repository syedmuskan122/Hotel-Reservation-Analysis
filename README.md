# 🏨 Hotel Reservation Operations Analytics | Power BI

## 📌 Project Overview

This project focuses on analyzing hotel reservation data to understand booking patterns, cancellation trends, customer behavior, and hotel operations.

Using **Power BI**, I transformed raw reservation data into an interactive dashboard that helps identify important trends and supports data-driven decision-making.

The project demonstrates my skills in data cleaning, data analysis, data visualization, and business intelligence.

## 🎯 Project Objectives

- Analyze hotel reservation trends and booking patterns.
- Understand reservation cancellations and their impact.
- Explore customer booking behavior.
- Identify important operational trends.
- Build an interactive Power BI dashboard for business insights.
- Support better decision-making through data visualization.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Excel / CSV** – Dataset preparation and exploration

## 📊 Dashboard Features

The dashboard provides insights into:

- Reservation and booking trends
- Booking cancellations
- Customer and booking behavior
- Hotel reservation performance
- Key performance indicators (KPIs)
- Interactive filters and visualizations

## 🔍 Key Analysis Areas

The project explores hotel reservation data to understand:

- How reservation patterns change over time
- The relationship between bookings and cancellations
- Customer booking preferences
- Operational performance indicators
- Trends that can help improve hotel reservation management
